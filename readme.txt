VitaWell is a responsive web application built using Bootstrap. It is designed to help users track daily wellness activities and view helpful health information in a clean and modern interface.
Features:
Bootstrap components: buttons, popovers, carousel, tooltips, accordion, and modals
Responsive layout using Bootstrap grid system
Wellness tips carousel with navigation controls
FAQ section using accordion
Modals for daily check-in and viewing history
Additional Feature:
Toast notifications were implemented to provide user feedback when actions are performed (e.g., saving data or subscribing)
Design:
Soft and modern healthcare theme
Calm color palette (sage green, blush, sand, lavender)
Clean typography and subtle animations
This project demonstrates effective use of Bootstrap components, responsive design, and a professional user interface.
